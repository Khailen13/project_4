# Проект интернет-магазина

## Описание:
Проект интернет-магазина с использованием Django.
Создано и зарегистрировано новое приложение catalog.
Созданы следующие страницы:
* главная: http://127.0.0.1:8000/;
* контакты: http://127.0.0.1:8000/contacts;
* страницы продуктов: http://127.0.0.1:8000/{id_продукта}

Реализовано добавление нового продукта, редактирование и удаление существующего продукта.

## Использование:
*На стадии разработки*
