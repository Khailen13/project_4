# Проект интернет-магазина

## Описание:
Создано 2 приложения с использованием Django:
* для интернет-магазина;
* для блога.

Для обоих приложений реализован полный CRUD.

### Проект интернет-магазина.
Приложение зарегистрировано под именем "catalog".
Доступны следующие страницы:
* главная: http://127.0.0.1:8000/;
* контакты: http://127.0.0.1:8000/contacts;
* страницы продуктов: http://127.0.0.1:8000/{id_продукта}.

### Приложение для блога.
Приложение зарегистрировано под именем "blog".
Доступны следующие страницы:
* главная: http://127.0.0.1:8000/blogs;
* страницы записей: http://127.0.0.1:8000/blogs/{id_записи}.

## Использование:
*На стадии разработки*
