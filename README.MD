# Проект с использованием Django

## Описание:
Создано 2 приложения с использованием Django:
* для интернет-магазина;
* для блога.

Для обоих приложений реализован полный CRUD.

### Проект интернет-магазина.
Приложение зарегистрировано под именем "catalog".
Доступны следующие страницы:
* главная: http://127.0.0.1:8000/;
* контакты: http://127.0.0.1:8000/contacts;
* страницы продуктов: http://127.0.0.1:8000/{id_продукта}.

В целях защиты сайта от спама предусмотрен запрет на присваивание продуктам названия и добавлять в описание слова,
которые включены в список запрещенных слов:
* казино,
* криптовалюта,
* крипта,
* биржа,
* дешево,
* бесплатно,
* обман,
* полиция,
* радар.

При добавлении и редактировании продукта предусмотрена проверка цены на отрицательное значение.

Для работы с пользователями реализованы функции аутентификации.
При регистрации предусмотрены поля email, пароль, аватар, номер телефона и страна.
Заполнение полей email и пароль является обязательным.
Для неавторизованных пользователей доступна только страница со списком продуктов.

### Приложение для блога.
Приложение зарегистрировано под именем "blog".
Доступны следующие страницы:
* главная: http://127.0.0.1:8000/blogs;
* страницы записей: http://127.0.0.1:8000/blogs/{id_записи}.
